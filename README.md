# Rafael Lima — Personal Portfolio

Personal website for **Rafael Lima Ribeiro dos Santos**, focused on software development, cybersecurity, robotics, DevSecOps and industrial automation.

Built as a lightweight static site for GitHub Pages with no framework or build step.

## Structure

```text
rafael-lima-devbr.github.io/
├── index.html   # Portfolio content and semantic structure
├── styles.css   # Responsive dark interface
├── script.js    # Navigation, reveal effects and small interactions
└── README.md
```

## Sections

- introduction and current technical focus;
- profile and education;
- featured projects;
- robotics, research and programming activities;
- selected academic and technical highlights;
- technical stack;
- contact links.

## Local preview

Because the site is fully static, it can be previewed by opening `index.html` directly in a browser or by serving the repository with any simple local HTTP server.

## Deployment

This repository is intended for GitHub Pages at:

`https://rafael-lima-devbr.github.io/`

After changes are merged into the branch configured as the GitHub Pages source, GitHub can publish the updated site automatically.
