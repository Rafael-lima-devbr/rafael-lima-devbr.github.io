01 Main cybersecurity project

Phishpect

Problem. Help users identify potentially fraudulent pages before trusting a navigation.

Built. An experimental Microsoft Edge extension that combines local rule-based URL analysis with a local reputation database and risk-based intervention.

Technical distinction. The analyzer separates URL components, uses registrable-domain parsing, combines multiple evidence categories and keeps versioned tests and evaluation datasets for comparing analyzer revisions.

02 Experimental robotics

Autonomous Line-Following Robot

Problem. Control a line-following robot through turns, intersections, line gaps and obstacle conditions using sensor feedback.

Built. A Raspberry Pi robotics architecture with custom PID line following, differential-drive odometry, sensor-based decisions and movement-control routines.

Technical distinction. PID is used for line alignment while odometry estimates robot movement, allowing selected maneuvers to use estimated displacement instead of only fixed timing.
