01 Cybersecurity · Main project

Phishpect

Problem Detect potentially fraudulent pages early enough to give the user useful context before trusting a navigation.

Built An experimental Chromium browser extension, currently centered on URL/domain analysis, local reputation data and risk-based allow, warn or block decisions.

Technical focus Registrable-domain parsing, separated URL signals, evidence categories, versioned tests and evaluation datasets. Content-level signals such as forms, password fields, data destinations and identity/domain inconsistencies are planned expansion areas rather than current claims.

JavaScript · Manifest V3 · Browser Security · tldts / Public Suffix List

02 Robotics

Autonomous Line-Following Robot

Problem Navigate line segments, turns, intersections, gaps and obstacles using sensor feedback instead of a fixed movement script.

Built A Raspberry Pi control architecture with custom PID line following, differential-drive odometry, sensor-based decisions and recovery routines.

Technical focus PID handles line alignment while odometry estimates movement for selected maneuvers; the project also includes hardware calibration and testing utilities.

Python · Raspberry Pi · PID Control · Odometry · Sensors
